# RimDevTools 三批实施：第二批完成清单

完成日期：2026-11-06。

范围：工具自动更新、安装级互斥、配置保留式迁移、Windows 助手交接、回滚与恢复。工具版本提升为 `1.3.0`，程序集及发行包版本为 `1.3.0.0`；本批未执行公开发布或推送。

## 已完成

- [x] 新增 `update --check`、`update --dry-run`、`update` 和 `update status`，同步参数契约、帮助及两套核心 skill。
- [x] 普通命令启动使用 24 小时缓存，联网总预算最多 2 秒；失败退避 1 小时，损坏缓存可重建，业务 JSON 与退出码保持原行为。
- [x] 帮助、版本、状态查询和内部助手不触发启动联网检查；未知命令在项目发现及启动检查前直接拒绝。
- [x] 使用官方 GitHub 正式 Release 的 Tools 附件，排除草稿和预发布；规范三段/四段版本，不自动降级或重复安装同版。
- [x] 固定目标发行及附件，校验大小、API SHA-256 或发行 `.sha256` 附件；缺少或错误校验信息均拒绝安装。
- [x] ZIP 白名单拒绝越界、大小写冲突、链接、非受管理内容及异常解压大小，逐项核对包内清单。
- [x] 当前发行清单作为受管理文件基线；本地修改、删除、缺失基线及新路径冲突阻止整次提交。用户新增文件保留，旧受管理文件按清单移除。
- [x] JSONC 只补充缺失的 `existing_project_mode=false`，保留显式模式、游戏目标、注释、UTF-8 BOM、换行、未知字段及用户值；重复键、错误类型、未知结构版本和并发修改均拒绝覆盖。
- [x] 正式安装按正在运行的 EXE 定位，独立于工作目录；源码运行和未知旧安装拒绝自动安装。
- [x] 安装级文件门禁、业务租约及持久交接状态共同防止并发业务进入混合版本。
- [x] 独立隐藏助手确认交接后，主命令才返回 `scheduled`；助手等待原进程退出，执行文件替换和安装后验证。
- [x] 写入意图、原文件备份与事务日志支持反向恢复；新 EXE 不能运行时，可使用保留的独立助手恢复。
- [x] 状态区分 `none`、`scheduled`、`applying`、`succeeded`、`failed`、`rolledBack`、`recoveryRequired`。状态查询只读，能识别更新进程已退出的中断事务。
- [x] 恢复遇到未知并发修改时保留现场并阻止业务；正在运行的父进程/助手会阻止重复恢复，且不会改写原事务状态。
- [x] 工具保留最近三份已完成事务，未完成事务与无法确认的恢复数据不被清理。
- [x] 三种包均包含相同的更新能力和核心载荷；更新只改变项目私有工具，不自动替换游戏中的工具 Mod。

## 运行与发行位置

正式包仍由既有发布脚本生成到：

- `artifacts/RimDevTools-1.3.0.0-Template-RimWorld-1.6/`，及对应 `.zip`、`.zip.sha256`。
