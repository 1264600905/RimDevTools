# 技能与配方自动测试任务总结

## 本次完成内容

### 1. 制作配方测试改造
- 已将 Recipe 自动测试从原先的 `InfoCard` 语义切换为 `RecipeBillUi`。
- 当前链路为：
  - 选中工作台
  - 创建并打开 `Bill_Production` 的 `Dialog_BillConfig`
  - 截图
  - 关闭账单配置窗口
  - 自动补料并真实生产产物
- 截图目录已落到：
  - `UI/RecipeBillUi`

### 2. SkillPocketMap 测试链路
- 新增 `SkillPocketMap` 自动测试分类。
- 已接入：
  - manifest/discovery/planning
  - scope/category 映射
  - runner 调度与并发统计
  - batch limit
  - screenshot 分组目录 `combat/SkillPocketMap`
- 当前技能测试流程为：
  - 发现目标模组 `AbilityDef`
  - 创建独立 pocket map
  - 根据 `AbilityDef` 反查拥有该技能的 `PawnKindDef`
  - 生成施法者
  - 生成 5 个敌对单位作为靶子
  - 60 秒内循环尝试施法
  - 每 10 秒执行一次 `ResetCooldown()`
  - 施法成功后标记 `skill_casted`
  - 输出截图与 overlay

### 3. 技能截图与 Overlay
- 已为 SkillPocketMap 结果写入：
  - `OverlayLine1 = 技能名`
  - `OverlayLine2 = defName`
  - `OverlayLine3 = Caster`
  - `OverlayLine4 = Enemies`
- 成功/失败都会尝试截图。

### 4. 测试脚本约束
- 已明确补充 `规范化测试/run_test.py` 文件头注释：
  - `注意绝对禁止并发执行此脚本，因为游戏只有一个player.log文件，如果并发执行会导致日志内容混乱，甚至可能导致游戏崩溃。`
